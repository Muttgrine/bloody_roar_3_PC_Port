  HOW TO PLAY
  -----------
  Double-click:

     Play.bat

  That's it. The game will start!

  You'll see:
     1. The Muttgrine Studios logo
     2. HD intro videos (Activision, Hudson, BR3 cinematic)
     3. The game's title screen — press Start to play!


  CONTROLS (KEYBOARD)
  -------------------
     Arrow Keys  =  Move your character
     X key       =  Confirm / Attack (Cross button)
     Z key       =  Square button
     C key       =  Circle button
     V key       =  Triangle button
     Q / E       =  L1 / R1 shoulder buttons
     1 / 3       =  L2 / R2 triggers
     Enter       =  Start / Pause
     Right Shift =  Select


  CONTROLS (CONTROLLER)
  --------------------
  Just plug in an Xbox, PlayStation, or Switch controller.
  It works automatically. No setup needed.


  IN-GAME MENU (F1)
  -----------------
  While playing, press F1 on your keyboard to open the menu.
  You can:

     - Change resolution (1x, 2x, 3x, 4x — makes it look sharper)
     - Change picture look and text sharpness
     - Go fullscreen (also F11)
     - Quick save (F5) and quick load (F8)
     - Open the Netplay Lobby (play online with friends!)
     - Quit the game


  TIPS FOR BEST PERFORMANCE
  -------------------------
  - Close Chrome, VS Code, and other heavy apps before playing.
  - If your laptop has two GPUs (Intel + NVIDIA), make sure
    Windows uses the NVIDIA one:
    Settings > Display > Graphics > Add BloodyRoar3.exe > High Performance
  - Press F1 and try different resolutions.
    1x is fastest. 2x-4x looks sharper if your GPU can handle it.


  HOW TO PLAY ONLINE WITH FRIENDS
  --------------------------------
  1. ONE person starts the server:
     Open the "netplay" folder.
     Double-click: start_server.bat
     Leave that window open. It says "Ready for connections."

  2. Tell your friends your IP address.
     (Google "what is my IP" to find it)

  3. Everyone opens the game.
     Press F1 during gameplay.
     Select "Netplay Lobby" to host or join a room.

  4. The host creates a room.
     A code appears like: BR3-XK4M2
     Share that code with your friend.

  5. Your friend joins using the code.
     You fight!


  SKIP INTROS
  -----------
  Want to skip the intro videos and go straight to the game?
  Double-click "Play (Skip Intros).bat" instead.


  TROUBLESHOOTING
  ---------------
  Game won't start
     Make sure BloodyRoar3.exe and SDL2.dll are in the same folder.

  Game is slow or choppy
     Press F1 and set Resolution to 1x.
     Close other programs.
     Make sure Windows uses your dedicated GPU (see tips above).

  No sound
     Check your Windows volume.

  Controller not working
     Try unplugging and replugging it.
     Make sure the game window is focused (click on it).

  Screen is black at startup
     Wait a few seconds — the intro videos play first.
     Press any key to skip a video.

  HD intros have no audio
     You need ffplay.exe installed (comes with ffmpeg).
     Get it from: https://www.gyan.dev/ffmpeg/builds/
     Put ffplay.exe in this folder or install ffmpeg system-wide.
